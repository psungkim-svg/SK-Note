## v7.6.0 변경점 (제품 방향: 텍스트 중심 · 사진은 저장하지 않음)

### 카메라 제거 · 사진 삽입 제거
- 편집 툴바의 📷(탭=갤러리 / 길게=카메라)와 카메라 입력을 없앴습니다.
- 사진을 노트 안에 넣던 방식(압축 후 base64로 본문에 저장)과 붙여넣기 삽입을 중단했습니다. 붙여넣으면 "사진은 노트에 저장하지 않습니다" 안내.
- 이미 옛 노트에 들어 있던 사진은 계속 보이고 삭제할 수 있습니다(새로 넣기만 불가).

### 🖼 사진 링크 (새 기능)
- 편집 중 🖼 → 폰의 사진 선택기에서 고르면 노트에 **🖼 사진이름** 칩이 들어갑니다. 탭하면 사진이 열립니다.
- 노트에 저장되는 것은 칩 한 줄과, 별도 표(`sk.photolinks`)의 아주 작은 참조(uri·이름·크기·추가일, 장당 200 byte 안팎)뿐입니다.
  **10 MB 사진을 연결해도 노트는 텍스트 크기 그대로**입니다. 사진 파일·base64·썸네일·업로드 없음.
- Vault 노트의 사진 참조는 Vault 암호문 안에 함께 암호화됩니다.
- 백업 파일에는 참조 표가 포함되고(사진은 없음) 복구 시 병합됩니다.
- **Android 앱(Capacitor)**: 시스템 Photo Picker + 영구 읽기 권한으로 언제든 열림, 사진은 갤러리/Google Photos에서 표시. 추가 권한 없음. 사양: `ANDROID_PHOTOLINK_PLUGIN_KO.md`
- **웹 브라우저**: 브라우저는 영구 참조를 줄 수 없어, 고른 그 세션 동안만 볼 수 있습니다(저장 안 함). 다음에 열면 "Android 앱에서는 언제든 열립니다" 안내.
- 사진이 삭제되어 열 수 없으면 안내 토스트. 칩을 지우면 참조도 자동 정리.

### 동기화(Supabase)
- 코드는 유지(프리미엄 계획), 기본은 꺼짐. 사진 참조는 동기화 대상 컬럼에 포함되지 않습니다(기기 고유 참조).

## v7.5.8 변경점 (사용자 피드백 5건 반영)

### 1) Vault 비밀번호 — 안내 문구 대신 곧바로 비밀번호 팝업

- 처음 비밀번호를 만드는 경우에도 "다시 Vault를 열어 주세요" 없이 **바로 Vault로 진입**합니다.

  편집기 ⋮의 옛 '먼저 Vault를 열고…' 문구 경로는 삭제했습니다(아래 3번).

### 4) 상단 고정 알림 — 고정 해제 전까지 유지

- 앱을 켜거나 전면으로 돌아올 때도 빠진 고정 알림을 다시 만듭니다(`syncPinnedNotifications`).

- 한계: 운영체제가 알림 권한을 끊거나 배터리 최적화로 서비스워커 자체를 죽이면 다음 앱 실행 때 복원됩니다.

### 5) 앱 아이콘의 작은 숫자 "1"

     - 📁 폴더 → 각 폴더 목록(누르면 그곳으로 이동)
     - 🔐 Vault → (잠겨 있으면 비밀번호 게이트) Vault 폴더 목록 + Vault 노트 목록

- 뒤로가기(Back)는 기존 한 겹 규칙 그대로: 2단계 → 1단계 → 노트 선택 목록 → 폴더 hub → main.

## 유지되는 보안·데이터 동작

- Vault는 AES-256-GCM v2 encrypted envelope 하나에 notes/folders/settings를 저장합니다.
- 새/변경 Vault 비밀번호는 최소 12자이며 PBKDF2-HMAC-SHA-256 210,000회 + random 16-byte salt를 사용합니다.
- normal note → Vault 이동은 password 확인 및 destination ciphertext persist 성공 **뒤에만** normal source를 제거합니다.
- v5 backup은 normal notes와 detached **ciphertext-only Vault snapshot**만 포함합니다. Vault 제목, 본문, Folder, settings 평문은 export/backup에 넣지 않습니다.
- Folder tile 길게 누르기와 Folder detail 제목 탭 rename은 ID/note 연결을 바꾸지 않습니다.
- normal Folder는 pastel-green, Vault Folder는 별도 Vault styling을 유지합니다.

## 가장 안전하고 간단한 backup 방법

1. 중요한 내용을 저장한 뒤 **Settings → Backup**을 누르세요. Vault가 있다면 Vault 저장이 끝난 뒤 실행합니다.
2. 내려받은 `sknote-backup-YYYYMMDD-HHMM.json` 파일을 즉시 **암호화된 클라우드 저장소 또는 암호화된 USB**에 복사합니다. 휴대폰 Downloads 한 곳에만 두지 마세요.
3. Vault password는 백업 파일과 같은 폴더/메모에 저장하지 말고, 신뢰할 수 있는 password manager 또는 별도 보관 수단에 보관합니다.
4. 매월 한 번, 새 브라우저 프로필이나 보조 기기에서 backup을 열어 normal note 복구와 Vault password 열기를 시험하세요. 운영 중인 원본 Vault 위에 시험 복구하지 마세요.
5. 최근 백업 2~3개를 날짜별로 남겨 두세요. 실수로 삭제한 뒤 만든 새 백업 하나만 남기는 일을 피할 수 있습니다.

## 배포 뒤 빠른 확인 (v7.5.3)

1. Settings 버전이 `v7.5.3`인지, 새 Service Worker가 적용됐는지 확인합니다.
2. **Vault 자동 잠금(실제 기기 핵심 시나리오)**: 5분/30분 설정 → Vault 진입 → normal Notes로 나감 → **앱을 백그라운드로 뺐다 들어오거나(페이지 새로고침 포함) 바로 🔐 재진입** → password gate가 **없어야** 합니다. timeout이 실제로 지나면(화면 오프 중 포함) gate가 돌아옵니다.
3. **체크박스 50% + 폴더 안 선택·삭제**: 노트를 길게 누르면 기존보다 작아진 체크박스가 우측 상단에 나타나는지(일반·폴더 안·Vault 안 모두). 폴더 상세에서 길게 눌러 선택 → ️로 삭제되는지. 폴더 타일 롱프레스에 이름 입력 창이 **안 뜨는지**.
4. **폴더명 인라인 변경**: 폴더 상세에서 왼쪽 상단 폴더명을 탭 → 그 자리에 현재 이름이 채워진 박스 → Enter/탭 = 저장, Esc = 취소. 일반 + Vault 폴더.
5. **폴더 4열 고정**: 폴더 목록(일반 + Vault)이 한 줄에 4개로 정렬되는지, ⋮ 메뉴에 '보기 방식'이 **없는지**.
6. (v7.5.2 유지) **Folder → 폴더 안의 노트 → 텍스트 입력 → Back**: 한 번에 한 겹(노트 → 폴더 상세 → 폴더 hub → main).
7. (v7.5.2 유지) **설정 → 노트 글자 굵기** 3단계, 모든 노트 동일 적용 · **⋮ 메뉴 배경 탭 닫기**.
8. (v7.5.2 유지) Vault bottom bar가 normal/All/Notes/📁 네 항목 + `＋` FAB.
9. (v7.5.2 유지) test data로 Backup restore 및 Vault password 열기 확인. (복원 노트에 노트별 굵기 오버라이드 없음)
