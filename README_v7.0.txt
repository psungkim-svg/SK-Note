soonenote v7.0  배포 파일
=========================

[교체할 파일 — 이 2개만 올리면 됩니다]
  index.html     (APP_VER = 7.0)
  sw.js          (VERSION = 7.0  → 캐시 이름 soonenote-v7.0)
  ※ 데이터 형식은 v6.9와 동일합니다. 마이그레이션 없음 — 기존 노트·폴더·금고 그대로 열립니다.

[v6.9 → v7.0 바뀐 것 5가지]

  1) 아래 바를 80%로, '전체'·'노트' 글자만 70%로 줄였습니다.
     · 바 높이 67px → 54px (80.6%)  ※ 320/360/412px에서 실측, 태블릿(1000px) 55px
     · '전체'·'노트' 칩 글자 23.8px → 16.66px (70.0%)
     · 폴더 이름 칩··🔐 글자는 23.8px 그대로 — 요청대로 '노트 쪽 글자만' 작아졌습니다.
     · 칩 높이 51px → 48px (터치에는 충분히 남깁니다)

  2) 폴더를 누르면 첨부 화면처럼 노트가 '세로 한 줄' ⇄ '가로 일곱 줄'로 펼쳐집니다.
     · 📁 폴더 관리(전체화면) 안에서 폴더 카드를 탭하면 그 폴더의 노트가 아래에 바로 뜨고,
       카드를 한 번 더 탭하면 노트가 열립니다. 닫을 때는 다시 탭.
     · '한 줄' 칩(1~7)으로 개수를 고릅니다. 고른 값은 저장되어
       노트 화면(전체·폴더 목록)의 박스 개수와 같은 값으로 쓰입니다 — 설정의 '박스'가 1~7로 늘어남.
     · 5개 이상이면 카드 폭이 45px까지 좁아져 본문이 한 글자씩 세로로 깨집니다.
       그래서 5개부터는 자동으로 '제목만' 타일로 바뀌어 읽을 수 있게 했습니다.
     · 즐겨찾기 ★·이름 변경·삭제도 화면을 닫지 않고 그 자리에서 됩니다(v6.9 유지).

  3) 폴더 화면 위에 툴바를 넣었습니다.
     · 첫 줄: 검색창 — 폴더 이름뿐 아니라 그 안 노트의 제목·본문까지 찾습니다
               ⇄ 폴더 배치(세로 한 줄 ↔ 가로 여러 개)   🗑 휴지통 바로 열기
     · 둘째 줄: '한 줄' 1~7 칩
     · 처음엔 한 줄에 다 담았는데 360px에서 검색창이 알약 하나로 눌리고 🗑 이 화면 밖으로
       밀려났습니다 → 두 줄로 나누고 칩에 최소너비를 주어 넘치지 않게 했습니다.

  4) T 창을 한 줄로 정리했습니다:  B  I  U  🔴 🔵 🟢  ⊘
     · 3색은 '글자색'입니다. 글자를 지정(선택)하면 그 글자만, 선택이 없으면 노트 전체에 적용됩니다.
     · ⊘ 는 색 지움(선택 없으면 전체에서 제거). 남은 빈 style 은 정리됩니다.
     · 보기 모드·편집 모드 양쪽에서 동작하고, 저장된 본문에 <span style="color:…"> 로 남아
       다시 열어도 색이 유지됩니다(실측 확인). 노트 배경색이 지워지는 일도 없습니다.
     · 노트 배경색은 예전처럼 '#edColorBtn(노트 색)' 버튼으로만 바꿉니다
       — v6.9에서 T 창으로 옮겼던 7색 배경 팔레트는 여기서 되돌렸습니다.

  5) 🔐 금고 — 감사 결과를 숨기지 않고 적습니다. (요청하신 대로 형식 변경은 하지 않았습니다)

     잘 되어 있는 것 (v7.0에서 실측 확인):
       · 노트 본문·제목은 sk.vault 안에 AES-GCM 암호문({"v":1,"iv":…})으로만 저장됨
       · 비밀번호 = 솔트 + PBKDF2-SHA256 210,000회 해시만 저장, 평문 PIN 은 어디에도 없음
       · 비밀번호 비교는 상수시간, 5회 실패 시 5초 쿨다운, 구버전 sha256 로그인은 자동 업그레이드
       · 잠긴 상태에서는 평문을 읽지 않고(VLT.load 생략), 잠그면 VLT.notes·키 즉시 해제
       · 잠금 중 일반 목록·검색·📁 매니저·하단 칩 어디에도 금고 노트 0건(노출 없음)
       · 동기화·dirty 경로에서 금고가 sk.notes 로 섞여 들어가지 않음, 콘솔 오류 0

     발견된 약점:
       · S-1 (높음) → 이번 판에 고쳤습니다.
         '← 일반 노트'(나가기)가 키만 버리고 평문을 세션 동안 메모리에 남겨 둬서,
         잠금 표시인데도 ui.vault=true 한 줄로 내용이 다시 보였고, 그 상태의 자동백업이
         sk.backups 에 금고 본문·제목을 평문으로 남겼습니다(v6.9에서 실측 ❌).
         [조치] 나가기 때 잠금 시간이 켜져 있지 않다면 메모리 평문을 폐기하고,
                잠긴 채로 백업하면 '일반 노트만 · 🔐 금고가 잠겨서 포함 안 함'을 띄웁니다.
                [실측] v7.0 은 백업·메모리 어디에도 본문/제목 평문이 없습니다.
       · S-2 (중간) → 고치지 않았습니다(승인 없이는 저장 형식을 바꿀 수 없어서).
         sk.vault.folders · sk.vault.settings 는 지금 평문 JSON 입니다.
         → 금고가 잠긴 상태에서도 '폴더 이름·개수'는 기기 저장소에 그대로 보입니다
           (감사 때 '비밀장부' 라는 이름이 평문으로 확인됨). 백업 파일의 vaultFolders 도 평문.
         노트 본문은 잠기고 이름은 새는 '이름은 새는 금고' 상태입니다.
         [제안] vault 폴더·설정까지 암호문 안에 넣고, 백업에는 vault 폴더를 넣지 않거나 별도 암호화.
                단, 이건 저장 형식이 바뀌므로 백업 + 마이그레이션 승인이 있어야 손댑니다.
       · S-3 (낮음) → 그대로. 시도 제한 5회 카운터가 메모리 전용이라 새로고침이면 초기화됩니다.
       · S-4 (낮음) → 그대로. 설정의 pinHash 가 사라지면 게이트가 '새 비밀번호 만들기'로 바뀌어
         기존 암호문이 열리지 않는 가용성 함정이 있습니다(유출은 아니고, 복구 불가 위험).

     ※ PIN 저장·백업 형식은 요청대로 손대지 않았습니다.
