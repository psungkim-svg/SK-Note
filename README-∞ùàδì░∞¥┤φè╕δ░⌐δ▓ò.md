# soonenote V6.4 — GitHub 업로드 방법

## 1. 이 폴더에 들어 있는 파일

```
index.html                    ← 앱 본체 (맨 위에 V6.4 표시)
sw.js                         ← 서비스워커
manifest.webmanifest          ← PWA 설정
vendor/supabase.min.js        ← Supabase 2.45.4 (오프라인용)
icons/icon-192.png
icons/icon-512.png
icons/icon-maskable-512.png
```

**7개 파일 전부**를 GitHub 저장소에 **폴더 구조 그대로** 올려 주세요.
`vendor` 폴더와 `icons` 폴더도 반드시 함께 올려야 합니다.

## 2. 업로드

1. GitHub 저장소 → **Add file** → **Upload files**
2. 압축을 푼 폴더 안의 파일을 **폴더째 드래그**
3. Commit 메시지에 `soonenote v6.4` → **Commit changes**
4. Vercel이 자동 배포 (1~2분)

| 항목 | 내용 |

**시간 기준**: 아침 05–11시 · 낮 11–17시 · 저녁 17–21시 · 밤 21–05시

**메시지를 늘리고 싶으면** `index.html` 의 `CHEERS` 에서
해당 시간대 배열에 `['이모지','문장']` 한 줄만 추가하면 됩니다.

> 폰 설정에서 "동작 줄이기(Reduce motion)"를 켜두신 분에게는
> 애니메이션이 자동으로 꺼지고 글자만 바로 나옵니다.

## 4. 폰에서 확인

- 상단 왼쪽에 **동그란 S 배지**가 보이면 새 버전입니다.
- 설정(⚙️) 맨 아래에 **soonenote / v6.4** 라고 표시됩니다.
- 화면이 전부 영어로 나옵니다.

한국어로 보시려면: **Settings → Language → 한국어**

## 5. ★ Supabase 보안 설정 (아직 안 하셨다면)

**Settings → Account · Sync → 🔒 Show security (RLS) setup SQL**
누르면 SQL이 복사됩니다 → Supabase → SQL Editor → 붙여넣기 → Run

이걸 안 하면 공개 키만으로 누구나 모든 노트를 읽고 지울 수 있습니다.
플레이스토어 심사 전 필수입니다.

## 6. 다음 버전을 만들 때

버전 번호는 **두 군데**만 고치면 됩니다.

- `index.html`  →  `const APP_VER='6.4';`  →  `'6.5'`
- `sw.js`       →  `const VERSION = '6.4';` →  `'6.5'`

맨 위 주석의 버전 표시도 같이 바꿔 주세요.

## 7. 참고 — 문구를 고치고 싶을 때

영어가 기본입니다. HTML 안의 영어 문구를 직접 고치면 됩니다.
다른 언어도 함께 고치려면 `index.html` 안의 사전을 수정하세요.

- `I18N_KO` (한국어) · `I18N_ES` (스페인어) · `I18N_JA` (일본어) · `I18N_ZH` (중국어)
- 응원 메시지는 `CHEERS` 에 언어별로 들어 있습니다.

# 부록 · Supabase RLS 가 뭔가요?

## 한 줄 요약
**동기화를 안 쓰시면 아예 신경 안 쓰셔도 됩니다.**
동기화를 쓰신다면 **딱 한 번** 해두셔야 하는 보안 설정입니다.

## 왜 필요한가
동기화를 켜려면 Supabase(서버)의 **공개 키**를 앱에 넣어야 합니다.
그런데 이 키는 HTML 안에 들어 있어서 **누구나 볼 수 있습니다.**

RLS(Row Level Security, 행 수준 보안)를 켜지 않으면
그 키를 본 사람이 **다른 사람의 노트까지 전부 읽고 지울 수 있습니다.**

RLS를 켜면 서버가 "이 사람은 자기 노트만" 이라고 막아 줍니다.

## 하는 법 (2분)

1. 앱에서 **⚙️ Settings → Account · Sync**
2. **🔒 Show security (RLS) setup SQL** 누름 → SQL이 복사됨
3. supabase.com 접속 → 내 프로젝트
4. 왼쪽 메뉴 **SQL Editor** → **New query**
5. 붙여넣기 → 오른쪽 아래 **Run**
6. `Success. No rows returned` 나오면 끝

## 확인
다시 **Test connection** 을 눌러 정상이면 완료입니다.

**폴더째 통째로 드래그** 하세요.

# 동기화 · 자주 묻는 것

## 저장은 자동인가요?
**네. 따로 저장 버튼을 누르실 필요 없습니다.**

- 글을 쓰고 **3초** 지나면 → 폰에 저장
- 그 뒤 **2.5초** 지나면 → 서버에 올라감
- 앱을 닫거나 화면이 꺼질 때도 즉시 저장됩니다

## Back 버튼으로 앱을 나갔다 다시 열면 로그인해야 하나요?
**아니요. 한 번만 로그인하면 계속 유지됩니다.**

앱을 완전히 종료했다 켜도 자동으로 로그인 상태가 복원되고,
상단 동기화 점이 **초록불**로 바뀌면서 새 노트를 받아옵니다.

> V6.3에서 고친 부분입니다. 이전 버전에서는 켤 때마다 다시 로그인해야 했습니다.

## 언제 동기화되나요?
- 노트를 고친 뒤 약 3초
- 앱을 열 때
- 다른 앱 갔다가 돌아올 때
- 60초마다 한 번씩
- 인터넷이 다시 연결될 때

## 새 폰에서 내 노트를 가져오려면?
1. 앱 설치
2. **Settings → Account · Sync** 에서 같은 URL·키 입력
3. **같은 이메일**로 로그인

로그인하는 순간 노트가 자동으로 내려옵니다.

## 동기화 점 색깔
| 색 | 뜻 |
|---|---|
| 회색 | 동기화 꺼짐 (설정 안 함) |
| 파랑 | 로그인됨 · 대기 중 |
| 노랑 | 지금 동기화 중 |
| 초록 | 동기화 완료 |
| 빨강 | 오류 (눌러서 원인 확인) |
