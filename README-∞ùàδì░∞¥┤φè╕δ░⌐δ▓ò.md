# soonenote V6.1 — GitHub 업로드 방법

## 1. 이 폴더에 들어 있는 파일

```
index.html                    ← 앱 본체 (맨 위에 V6.1 표시)
sw.js                         ← 서비스워커 (★ 이번에 크게 고침)
manifest.webmanifest          ← PWA 설정 (새로 만듦)
vendor/supabase.min.js        ← Supabase 2.45.4 (새로 만듦 · 오프라인용)
icons/icon-192.png            ← 아이콘 (새로 만듦)
icons/icon-512.png            ← 아이콘 (새로 만듦)
icons/icon-maskable-512.png   ← 아이콘 (새로 만듦)
```

**7개 파일 전부** GitHub 저장소의 **같은 위치(폴더 구조 그대로)** 에 올려야 합니다.
`vendor` 폴더와 `icons` 폴더도 반드시 함께 올리세요.

## 2. GitHub 업로드

1. GitHub 저장소 페이지 → **Add file** → **Upload files**
2. 압축을 푼 폴더 안의 파일을 **폴더째 드래그**
3. 아래 Commit 메시지에 `soonenote v6.1` 입력 → **Commit changes**
4. Vercel이 자동으로 새로 배포합니다 (1~2분)

## 3. ★ 폰에서 확인하는 법

헤더 왼쪽 위 배지가 **v6.1** 로 보이면 새 버전이 들어온 것입니다.
(예전에는 이게 안 바뀌는 게 문제였는데, 이번에 고쳤습니다.)

만약 그래도 옛날 화면이 보이면 **딱 한 번만** 아래를 해 주세요.
이번 업데이트 이후로는 다시는 필요 없습니다.

> 삼성 인터넷/크롬 → 설정 → 인터넷 사용 기록 삭제 → **캐시된 이미지 및 파일** 선택 → 삭제

## 4. ★★ Supabase 보안 설정 (꼭 하세요)

앱을 열고 **설정(⚙️) → 계정·동기화 → 🔒 보안(RLS) 설정 SQL 보기** 를 누르면
SQL이 클립보드에 복사됩니다.

Supabase 사이트 → 내 프로젝트 → 왼쪽 메뉴 **SQL Editor** → 붙여넣기 → **Run**

이걸 안 하면 앱에 들어 있는 공개 키만으로 **누구나 모든 사용자의 노트를 읽고 지울 수 있습니다.**
플레이스토어 심사 전에 반드시 끝내야 하는 항목입니다.

## 5. 다음 버전을 만들 때

버전 번호는 **두 군데**만 고치면 전부 따라옵니다.

- `index.html` 안의  `const APP_VER='6.1';`  → `'6.2'`
- `sw.js` 안의        `const VERSION = '6.1';` → `'6.2'`

맨 위 주석의 버전 표시도 같이 바꿔 주세요.
