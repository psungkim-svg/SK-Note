soonenote v6.8.1  배포 파일  (v6.8 핫픽스)
==========================================

[이번 버전에서 바뀐 파일 — 이 2개만 교체하면 됩니다]
  index.html     (APP_VER = 6.8.1)
  sw.js          (VERSION = 6.8.1  → 캐시 이름 soonenote-v6.8.1)

[v6.8 → v6.8.1  변경은 딱 두 가지입니다]
  P-1  폴더 관리(📁) 목록에서 폴더 '이름 글자'만 눌렸던 문제를 고쳤습니다.
       이제 행(줄) 어디를 눌러도 그 폴더로 이동합니다. (위·아래 여백 포함)
       ★ / 이름 변경 / 삭제 버튼과 입력창은 그대로 각자의 동작입니다.
  P-3  금고(🔐)가 잠긴 상태에서 백업을 '모두 복구'하면 금고 노트가
       사라지던(평문 "[]" 으로 덮어써지던) 문제를 막았습니다.
       잠겨 있을 때는 보관 노트만 건너뛰고, 일반 노트 복구는 평소대로 됩니다.
       결과 안내문에 "🔐 보관 노트는 잠겨서 건드리지 않음" 이 표시됩니다.

[그 밖의 것]
  · 디자인·저장구조·백업 형식(app:sk-note, v:4)·Vault 암호화·동기화: v6.8과 동일.
  · v6.7.1 백업 파일도 그대로 복원됩니다.
  · 캐시만 갱신되므로 데이터 이동·마이그레이션은 필요 없습니다.

[업로드 방법]
  1. 기존 배포 폴더에 index.html 과 sw.js 를 덮어씁니다.
  2. 폰에서 앱을 열고 화면을 아래로 당겨 새로고침(또는 앱 완전 종료 후 재실행).
  3. 설정 화면 맨 아래 버전이 'v6.8.1'로 보이면 성공입니다.

[문제가 생기면]
  v6.8 또는 v6.7.1 파일로 index.html, sw.js 를 되돌리면 즉시 롤백됩니다.
