# soonenote V6.6 — GitHub 업로드 방법

## 1. 이 폴더에 들어 있는 파일

```
index.html                    ← 앱 본체 (맨 위에 V6.6 표시)
sw.js                         ← 서비스워커
manifest.webmanifest          ← PWA 설정
vendor/supabase.min.js        ← Supabase 2.45.4 (오프라인용)
icons/icon-192.png
icons/icon-512.png
icons/icon-maskable-512.png
```

**7개 파일 전부**를 GitHub 저장소에 **폴더 구조 그대로** 올려 주세요.
`vendor` 폴더와 `icons` 폴더도 반드시 함께 올려야 합니다.

## 2. 업로드

1. GitHub 저장소 → **Add file** → **Upload files**
2. 압축을 푼 폴더 안의 파일을 **폴더째 드래그**
3. Commit 메시지에 `soonenote v6.6` → **Commit changes**
4. Vercel이 자동 배포 (1~2분)

# 부록 · Supabase RLS 가 뭔가요?

## 한 줄 요약
**동기화를 안 쓰시면 아예 신경 안 쓰셔도 됩니다.**
동기화를 쓰신다면 **딱 한 번** 해두셔야 하는 보안 설정입니다.

## 왜 필요한가
동기화를 켜려면 Supabase(서버)의 **공개 키**를 앱에 넣어야 합니다.
그런데 이 키는 HTML 안에 들어 있어서 **누구나 볼 수 있습니다.**

RLS(Row Level Security, 행 수준 보안)를 켜지 않으면
그 키를 본 사람이 **다른 사람의 노트까지 전부 읽고 지울 수 있습니다.**

RLS를 켜면 서버가 "이 사람은 자기 노트만" 이라고 막아 줍니다.

## 하는 법 (2분)

1. 앱에서 **⚙️ Settings → Account · Sync**
2. **🔒 Show security (RLS) setup SQL** 누름 → SQL이 복사됨
3. supabase.com 접속 → 내 프로젝트
4. 왼쪽 메뉴 **SQL Editor** → **New query**
5. 붙여넣기 → 오른쪽 아래 **Run**
6. `Success. No rows returned` 나오면 끝

## 확인
다시 **Test connection** 을 눌러 정상이면 완료입니다.

# 동기화 · 자주 묻는 것

## 저장은 자동인가요?
**네. 따로 저장 버튼을 누르실 필요 없습니다.**

- 글을 쓰고 **3초** 지나면 → 폰에 저장
- 그 뒤 **2.5초** 지나면 → 서버에 올라감
- 앱을 닫거나 화면이 꺼질 때도 즉시 저장됩니다

## Back 버튼으로 앱을 나갔다 다시 열면 로그인해야 하나요?
**아니요. 한 번만 로그인하면 계속 유지됩니다.**

앱을 완전히 종료했다 켜도 자동으로 로그인 상태가 복원되고,
상단 동기화 점이 **초록불**로 바뀌면서 새 노트를 받아옵니다.

> V6.3에서 고친 부분입니다. 이전 버전에서는 켤 때마다 다시 로그인해야 했습니다.

## 언제 동기화되나요?
- 노트를 고친 뒤 약 3초
- 앱을 열 때
- 다른 앱 갔다가 돌아올 때
- 60초마다 한 번씩
- 인터넷이 다시 연결될 때

## 새 폰에서 내 노트를 가져오려면?
1. 앱 설치
2. **Settings → Account · Sync** 에서 같은 URL·키 입력
3. **같은 이메일**로 로그인

로그인하는 순간 노트가 자동으로 내려옵니다.

## 동기화 점 색깔
| 색 | 뜻 |
|---|---|
| 회색 | 동기화 꺼짐 (설정 안 함) |
| 파랑 | 로그인됨 · 대기 중 |
| 노랑 | 지금 동기화 중 |
| 초록 | 동기화 완료 |
| 빨강 | 오류 (눌러서 원인 확인) |

## 7번이 왜 중요했나

글자를 키우는 건 되는데 **줄이는 게 전혀 안 됐습니다.**
크기를 바꿀 때마다 `<span>`을 한 겹씩 더 씌웠는데, CSS에서는 **가장 안쪽 값이 이깁니다.**
그래서 24pt로 키운 뒤 10pt로 줄여도 화면은 계속 24pt였습니다.

이제 안쪽에 있던 크기 지정을 **먼저 지우고** 새로 입히므로 정상 동작합니다.

```
24pt → 32.0px
10pt → 13.3px   (예전에는 32px 그대로였음)
 8pt → 10.7px
```

# V6.6 — 가장 중요한 수정

## "노트가 안 열림" 의 원인

새 버전이 배포되면 서비스워커가 제어권을 넘겨받는데,
이때 앱이 **곧바로 화면을 새로고침**하고 있었습니다.

문제는 이 일이 **노트를 쓰는 도중에도** 일어난다는 것이었습니다.
노트를 여는 순간 화면이 새로고침되니 "안 열린다"고 느껴졌고,
저장 전 글자가 사라질 수도 있었습니다.

**이제는** 노트를 편집 중이거나 무언가 열려 있으면 새로고침을 **미룹니다.**
앱을 잠시 벗어났다 돌아올 때 조용히 반영되고, 그 전에 초안을 먼저 저장합니다.

# 인터넷이 끊겨도 쓸 수 있나요?

**네. 전부 됩니다.** 실제로 인터넷을 끊고 시험했습니다.

| 상황 | 결과 |
|---|---|
| 인터넷 없이 앱 열기 | ✅ |
| 기존 노트 보기 | ✅ |
| 기존 노트 수정 | ✅ |
| 새 노트 작성 | ✅ |
| 앱 껐다 켜기 | ✅ 작성분 그대로 |
| 인터넷 복구 | ✅ 자동으로 서버에 올라감 |

노트는 **폰 안에 먼저 저장**되고, 서버는 '복사본'일 뿐입니다.
그래서 비행기 모드에서도 평소처럼 쓰시면 되고,
인터넷이 돌아오면 밀린 것이 알아서 올라갑니다.

> 단, `vendor` 폴더를 올리셔야 완전한 오프라인이 됩니다.
> (안 올리셔도 동기화는 인터넷에서 자동으로 받아와 동작합니다)
