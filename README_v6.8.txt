soonenote v6.8  배포 파일
=========================

[이번 버전에서 바뀐 파일 — 이 2개만 교체하면 됩니다]
  index.html     (APP_VER = 6.8)
  sw.js          (VERSION = 6.8  → 캐시 이름 soonenote-v6.8)

[변경되지 않은 파일 — 이미 서버에 있다면 그대로 두어도 됩니다]
  manifest.webmanifest
  icons/icon-192.png, icon-512.png, icon-maskable-512.png
  vendor/supabase.min.js

[업로드 방법]
  1. 기존 배포 폴더에 index.html 과 sw.js 를 덮어씁니다.
  2. 폰에서 앱을 열고 화면을 아래로 당겨 새로고침하거나,
     앱을 완전히 종료 후 다시 실행하면 v6.8로 갱신됩니다.
  3. 설정 화면 맨 아래 버전이 'v6.8'로 보이면 성공입니다.

[v6.8 변경 요약]
  · 검색: 폴더 안에 있어도 일반 메모 전체에서 찾습니다.
  · 검색 결과 카드에 어느 폴더의 메모인지 작게 표시됩니다.
  · 하단바: 전체 | 노트 | ★즐겨찾기 2개 | 지금 보는 폴더 | 📁 | 🔐
  · 폴더 관리(📁)에서 ★로 즐겨찾기 지정(최대 2개), 이름을 누르면 바로 이동.
  · 긴 폴더 이름은 칩에서 말줄임 처리, 검색 중에는 폴더 선택 표시가 잠시 꺼집니다.

[데이터 안전]
  메모/폴더/설정 저장 구조, 백업 파일 형식, Vault 암호화, 동기화 구조는
  v6.7.1과 완전히 동일합니다. 기존 백업 파일도 그대로 복원됩니다.

[문제가 생기면]
  v6.7.1 파일로 index.html, sw.js 를 되돌리면 즉시 롤백됩니다.
